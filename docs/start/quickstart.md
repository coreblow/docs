# Quick Start

Install **CoreBlow v2.3.1** (requires **Node.js 22.12+**) and launch the interactive setup wizard:

```bash
npm install -g coreblow
coreblow
```

Or start the local Gateway directly:

```bash
coreblow onboard
coreblow gateway run
```

To hand an active terminal session off to **CoreBlow Studio Desktop** at any time:

```bash
coreblow desktop --session latest
```
