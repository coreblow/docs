# Windows Installation

## npm (Node.js >= 22.12)

```powershell
npm install -g coreblow
coreblow
```

## CoreBlow Studio Desktop

Download the Windows `.exe` installer from [GitHub Releases](https://github.com/coreblow/coreblow/releases). CoreBlow Desktop runs natively on Windows with a built-in System Tray, OS-aware PATH/shell handling, and `electron-updater` update checks. See [CoreBlow Desktop](/platforms/desktop).
