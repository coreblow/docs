# macOS Installation

## Homebrew (CLI & Gateway)

```bash
brew install coreblow/tap/coreblow
coreblow
```

## npm (Node.js >= 22.12)

```bash
npm install -g coreblow
coreblow
```

## Nix Flake

```bash
nix run github:coreblow/nix-coreblow
```

## CoreBlow Studio Desktop

Download the signed `.dmg` or `.zip` release archive from [GitHub Releases](https://github.com/coreblow/coreblow/releases). Built-in Menu Bar controls and automatic update notifications are included; see [CoreBlow Desktop](/platforms/desktop).
